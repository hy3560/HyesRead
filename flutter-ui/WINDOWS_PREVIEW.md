# HyesRead Windows 便携版

解压 ZIP 中的全部文件，双击 `HyesRead.exe` 即可运行。请保留同目录的 DLL 文件和 `data` 文件夹；单独复制 EXE 无法正常启动。

本便携版与既有 HyesRead 桌面程序分开保存书库。升级或更换设备前，请先备份自己导入的书籍和应用数据。遇到运行库缺失提示时，可安装微软 Visual C++ 2015–2022 x64 运行库。

界面支持浅色和深色、书架管理、阅读进度、TXT / Markdown、EPUB 和 PDF。部分格式的全文搜索及大型书籍性能仍有局限，详见项目 README。

当前构建未签名，不包含安装器或自动更新。
