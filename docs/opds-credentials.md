# 在线目录账号

Windows 的在线目录中分别填写 OPDS 地址、账号和密码。不需要登录的目录只填写地址即可。旧版写在地址中的账号密码会在启动或打开目录时迁移。

## 保存和使用

- 使用 Windows Credential Manager 保存登录信息，通过 keyring 3.6.3 的 `windows-native` 后端调用系统接口。依赖仅在 Windows 编译，许可证为 MIT/Apache-2.0。
- 系统凭据命名空间按 Tauri app identifier 隔离；正式应用与自动验收应用使用不同空间。
- 条目标识使用完整目录地址的 SHA-256，避免 Windows 名称不区分大小写和账号字段长度上限影响 `/OPDS` 与 `/opds` 等不同目录。
- `hyes_catalogs.json` 只保存去掉账号密码的地址与目录名称。备份不包含系统凭据；换设备后需要重新填写登录信息。
- 请求分类、下一页和下载时，根据最初选择的目录读取凭据。只向相同协议、主机和端口发送；跨源链接不附带该账号，重定向也不能更换源。
- 携带账号的远程请求必须使用 HTTPS；本机回环地址允许 HTTP。Authorization 头标记为敏感，凭据库失败只返回固定错误信息。
- 移除目录时删除其系统凭据。目录元数据写入失败可能留下没有凭据的旧条目，重新填写账号即可恢复。

## 升级迁移

旧 URL 中的账号密码先写入系统凭据库，全部成功后再更新目录 JSON。系统凭据库不可用时保留原条目并报告目录读取错误，本地书籍仍可阅读。保留旧数据意味着迁移失败时旧 JSON 仍有原来的明文账号；需要恢复系统凭据库后重试。

迁移使用字段更新队列，并合并同时发生的迁移请求。它不是全库事务，不会删除用户旧备份或替换已经导出的文件。

## 验证与边界

Rust 回归覆盖旧 URL 迁移、跨源隔离、HTTPS 限制、百分号/Unicode 编码和 Windows 系统凭据的实际存取删除。原生应用验收继续覆盖私有分类/分页、进程重启、普通 JSON 无密码、旧版迁移和删除后拒绝匿名登录。

系统凭据库保护磁盘保存方式，不防止已控制当前用户会话的程序读取凭据。Android 与网页当前没有 OPDS 入口，本次没有声称它们已接入 Android Keystore 或浏览器凭据保存。

参考：[Microsoft 密码处理指南](https://learn.microsoft.com/en-us/windows/win32/secbp/handling-passwords)、[keyring 3.6.3 API](https://docs.rs/keyring/3.6.3/keyring/struct.Entry.html)。
