# 本机书库扫描

Windows 在后台线程读取所选目录，每 32 本向书架发送一批结果。扫描时可以继续查看已有书籍，也可以点击「取消扫描」。同一时刻只运行一个目录扫描。

## 数据处理

- 新结果在扫描期间作为临时预览；完整扫描结束后再更新书架与添加时间。
- 取消扫描会丢弃临时预览，保留原有书架、导入列表和添加时间。
- 遇到无权读取或已消失的文件、子目录，会跳过并提示数量；部分结果不能用来删除原有记录。
- 隐藏目录与符号链接不递归读取。元数据无法解析的书籍保留文件名等基础信息，能列入书架不代表正文可读。
- 取消在文件之间生效，当前书籍的元数据解析需要先结束。扫描仍保留完整结果，内存会随书目和封面增加。
- 系统传入书籍先完成 schema 检查；规范化和导入使用同一字段更新队列，避免启动时旧快照覆盖新导入。

## 验证范围

`cargo test --locked` 包括 10,000 个实际 TXT 文件、1,000 个 EPUB/PDF/TXT 混合文件、批次上限、取消与重新扫描。这里的文件是合成夹具，未覆盖大型复杂出版物、网络盘、冷缓存或峰值内存。

`pnpm test:native` 在独立的 `com.hyes.read.acceptance` 数据目录中验证 Windows WebView2 的实际阅读、扫描、取消、书架重启恢复和备份恢复。验收安装包使用独立标识，只用于自动化检查；正式安装包从 GitHub Release 下载。

`tests/e2e/reading.spec.ts` 同时验证桌面和手机网页的实际阅读，以及扫描监听清理、取消和迁移与导入并发的数据保留。

Android 和手机网页继续通过文件导入管理书籍；本机目录扫描属于 Windows 功能。Android 真机验收需要独立完成。
